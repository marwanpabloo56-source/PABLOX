# PABLOX

نظام مستقل لإدارة طلبات المطاعم.

## المرحلة الأولى
واجهة تجريبية عربية لإدارة الطلبات تعمل على الكمبيوتر والموبايل.

## خارطة الطريق
1. لوحة الطلبات التجريبية.
2. تسجيل الدخول وقاعدة البيانات مع عزل بيانات كل مطعم.
3. استقبال طلبات المواقع عبر واجهة API آمنة.
4. الطباعة الحرارية عبر موصل محلي.
5. التكامل مع أنظمة الكاشير التي تدعم الربط.

> هذه نسخة تجريبية وليست نظام كاشير جاهزًا للإنتاج.
